# AI Mobile Control Agent

A production-quality AI-powered Android Phone Control System that lets users interact with their mobile device using both voice and text commands via a centralized dashboard.

## Overview

This project is built using a modern monorepo architecture consisting of:
- **Client**: A React 19 + Vite dashboard for real-time interaction.
- **Server**: A Node.js + Express API backend for AI intent parsing and WebSocket communication.
- **Android**: A Kotlin-based Android application that executes device-level commands.
