# Installation Guide

## 1. Prerequisites
- Node.js (v18+)
- MongoDB (Local or Atlas)
- Android Studio (for mobile compilation)

## 2. Server Setup
1. Navigate to `server/`
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill the variables.
4. Run `npm run dev`

## 3. Client Setup
1. Navigate to `client/`
2. Run `npm install`
3. Copy `.env.example` to `.env` and fill the variables.
4. Run `npm run dev`

## 4. Android Setup
1. Open the `android/` folder in Android Studio.
2. Sync Gradle files.
3. Build and Run on your emulator or physical device.
